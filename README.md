The funniest one-line pickup line a robot could use — my entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on [make.fun](https://make.fun). A robot flips the usual script: instead of proving you're human, it's been proving *it's* human all day, just for one conversation.

> Are you a CAPTCHA? Because I've spent all day proving I'm not a robot just to talk to you.

`main.py` (Python 3, standard library only) prints the line and writes it to `entry.txt` in the make.fun output directory.
